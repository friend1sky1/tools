结论速记

  • 对勾：ab > 0 时出现两个「勾」，顶点 (±√(b/a), ±2√(ab))，最值 ±2√(ab)。
  • 飘带：ab < 0 时没有极值，两段各自单调，图象像一条斜飘带。
  • 骨架：x = 0 与 y = ax 是两条渐近线，曲线永远贴着它们走。
  • 拆解：y = ax + b/x，纵坐标 = 渐近线上的高度 ax 加上偏移 b/x。
  • 奇函数：f(−x) = −f(x)，图象关于原点中心对称。
